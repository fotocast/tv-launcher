📺 TV Launcher – for the Mac connected to your TV

Install this only on the Mac that is connected to your TV. It sets everything up for you:

  1. The TV Launcher server starts automatically whenever you log in.
  2. It opens Joyn, YouTube and your links in the browser (Firefox, Chrome or Safari).
  3. It serves the iPhone/iPad web app.
  4. The Bluetooth setup assistant no longer pops up at startup when no keyboard is connected.

Click Continue and Install (you'll be asked for your password).
