On the Mac connected to the TV (server)

  1. System Settings → Privacy & Security → Accessibility: turn on “VoiceServer” (it presses play/pause, seek and fullscreen keys). If it is not listed, add it with + – the file is in your home folder at TheVoiceServer/VoiceServer.
  2. Optional: Screen & System Audio Recording for “VoiceServer” – needed for “Bildschirm anklicken” (click on the screen) in the app.
  3. Sign in to Joyn in the browser (Firefox, Chrome or Safari).
  4. To run without a keyboard: Users & Groups → Automatically log in and Lock Screen → Require password: Never.
  5. If the firewall asks about incoming connections: Allow.

On your laptop (app)

Open “TV Launcher” from the Applications folder. It finds the server on the same Wi-Fi automatically (allow “Local Network” when asked).

iPhone

In Safari open http://<name-of-the-TV-Mac>.local:8081 → Share → Add to Home Screen. The exact address is shown in the app's settings.

Uninstall: sudo bash "/Library/Application Support/TV Launcher/uninstall.sh"
